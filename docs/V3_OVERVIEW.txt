PORTFOLIO RISK ENGINE — V3 FINAL OVERVIEW
=========================================
Version: V3 — Performance Analytics
Status: COMPLETE (local verification reported November 7, 2026)

1. PURPOSE
----------
Extend the V1 market-data foundation and V2 portfolio accounting/FX layer with
historical performance and risk-adjusted performance statistics. Results are
accessible through the command-line application, without requiring a GUI.

2. IMPLEMENTED CAPABILITIES
---------------------------
- Historical adjusted-price performance for a user-supplied portfolio.
- Currency normalization into a selected base currency (e.g., CAD), using
  historical FX observations rather than treating USD and CAD prices alike.
- Hypothetical constant-mix portfolio return series using snapshot weights.
- Cumulative return and compound annual growth rate (CAGR).
- Annualized return volatility, Sharpe ratio, and Sortino ratio.
- Maximum drawdown and best/worst observed common-date return periods.
- Per-asset performance summaries and asset-return correlation matrix.
- Optional benchmark comparison, including benchmark CAGR, volatility,
  maximum drawdown, portfolio beta, tracking error, and information ratio.
- CLI performance command and documented sample portfolio input.
- Offline regression and numerical tests; prior V1/V2 functionality retained.

3. SOFTWARE ORGANIZATION
------------------------
Quantitative formulas and time-series analysis are kept separate from data
retrieval, FX handling, and CLI presentation. The central performance logic
can be reused later by backtesting, risk models, and the planned dashboard.

5. LIMITATIONS AND ASSUMPTIONS
------------------------------
- V3 computes a hypothetical DAILY CONSTANT-MIX return series using present
  allocation weights, not the account's actual transactions or cash flows.
- Daily constant-mix implies mathematical daily restoration of weights; V3
  has no trades, transaction costs, slippage, taxes, or feasible execution.
- All assets are compared on common closing dates; non-overlapping sessions
  are excluded. In the observed sample, BTC-USD had 1,042 observed dates but
  only 702 common dates with the other investments.
- Metrics depend on the selected historical window, provider data, adjusted
  prices, exchange rates, and assumed risk-free rate.
- Current weights applied retrospectively do not establish that these weights
  were chosen without hindsight, or that the strategy will work in future.
- Actual tradeable strategy simulation, transaction costs, and scheduled
  rebalancing belong to V4.
- Model-based risk estimates and VaR backtesting belong to V5.
