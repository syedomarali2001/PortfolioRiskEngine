PORTFOLIO RISK ENGINE — V1 FINAL OVERVIEW
========================================
Milestone: Foundation & Market Data Ingestion
Status: COMPLETE — verified locally on Windows, November 7, 2026

PROJECT PURPOSE
---------------
Build a modular, testable Python foundation for a multi-asset portfolio
construction, risk analysis, and historical backtesting application.
V1 establishes data ingestion and validation only; it deliberately does not
calculate portfolio weights, portfolio returns, or risk statistics yet.

IMPLEMENTED IN V1
-----------------
1. A Python package with separate modules for models, file input, market-data
   providers, quality checks, FX mapping, disk caching, service logic, and CLI.
2. CSV/TXT/TSV imports using symbol, market_value, and currency fields.
   CAD and USD input values are supported; invalid amounts, malformed records,
   and duplicate symbols are rejected rather than silently accepted.
3. A replaceable market-data provider interface, with an initial Yahoo Finance
   implementation for historical adjusted closing prices.
4. CAD/USD exchange-rate retrieval via USDCAD=X, without converting amounts yet.
5. Historical price data-quality checks, warning metadata, and date handling.
6. Local on-disk caching so repeated data requests can reuse prior responses.
7. CLI commands for portfolio validation and market-data fetching.
8. Offline automated tests and package/project setup.

COMMANDS
--------
From the project root on Windows PowerShell:

  .\.venv\Scripts\python.exe -m pytest
  .\.venv\Scripts\python.exe -m portfolio_risk validate examples\sample_portfolio.csv
  .\.venv\Scripts\python.exe -m portfolio_risk fetch examples\sample_portfolio.csv --include-fx

The second fetch normally uses cached responses until the configured cache
expires. Live-data success depends on the external provider being available.

IMPORTANT DATA CONTRACTS AND LIMITATIONS
----------------------------------------
- market_value is an entered current holding value in the indicated currency;
  it is not a share count, purchase price, or historical transaction record.
- V1 does not add CAD and USD numbers together or derive portfolio weights.
- Adjusted price history is sourced from a third party and may change later.
- Yahoo symbol coverage is broad but not universal; symbol and data availability
  are provider-dependent.
- Crypto and exchange-listed securities have different trading calendars.
- Currency and corporate-action assumptions will be made explicit in later
  versions before calculating historical multi-asset returns.
- The first version has no portfolio-risk outputs, strategy simulation,
  optimization, security valuation, or GUI.
- External market data are research inputs; provider terms and redistribution
  rights must be reviewed before public datasets or paid services are offered.
