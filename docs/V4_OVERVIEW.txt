Portfolio Risk Engine — V4 Final Overview
========================================
Milestone: V4 Historical Portfolio Backtesting
Status: COMPLETE — local validation reported November 7, 2026

1. PURPOSE
V4 turns V3's descriptive constant-mix return analysis into an explicit
historical simulation of investments, allocation drift, rebalancing, and
trading fees. It is a research/backtesting framework, not a reconstruction
of real brokerage account performance.

2. IMPLEMENTED FEATURES
- Shared historical price and FX inputs inherited from V1–V3.
- Five simulated strategies with the same initial allocations and capital:
  buy-and-hold, monthly, quarterly, semiannual (June/December), and annual.
- End-of-period rebalancing at the final available common closing date.
- Optional proportional fee in basis points of traded notional; 0 bps default.
- Initial purchases also incur proportional fees when a nonzero fee is set.
- Results include ending value, CAGR, volatility, Sharpe, maximum drawdown,
  fee totals, number of rebalances, and buy-and-hold terminal weight drift.
- Optional SPY benchmark comparison in a common CAD base currency.

3. VERIFIED LOCAL EXECUTION
- Automated test suite: 152 tests passed (per user's local terminal output).
- Live historical backtest ran for 702 common closing-price observations,
  January 2, 2024 to November 6, 2026 (701 return intervals).
- Historical backtest with SPY benchmark completed.

6. DATA AND METHODOLOGICAL LIMITATIONS
- This simulation applies TODAY'S supplied portfolio target weights to
  earlier dates; it is not the user's actual historical account performance.
- Adjusted-close prices approximate total returns, and are not necessarily
  executable transaction prices.
- Rebalances execute at idealized closing prices; no bid/ask spread, market
  impact, taxes, or deposits/withdrawals are modelled.
- Fractional asset units are allowed.
- Only common market closing dates are used; Bitcoin's non-overlapping
  weekend sessions are discarded in aligned series.
- Reported annualized performance does not guarantee future outcomes.
- The CLI table heading currently prints literal formatting placeholders;
  this is a presentation bug, not evidence of an accounting failure.
