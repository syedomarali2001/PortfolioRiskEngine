PORTFOLIO RISK ENGINE — V5 FINAL OVERVIEW
========================================
Status: Completed after the user's local test on 2026-11-07.
Public release: deferred until V9.

PURPOSE
-------
Extend V4's simulated portfolio strategies to explain portfolio volatility,
estimate losses under historical/normal return models, test those risk estimates
using prior-only rolling windows, and explore observed or hypothetical shocks.

DELIVERED
---------
1. Covariance-based marginal and component volatility attribution, using final
   V4 simulated weights and trailing asset returns. Shows portfolio and
   standalone annualized volatility, absolute contributions and risk shares.
2. Historical and Gaussian-normal one-common-close VaR and Expected Shortfall
   at 95% and 99% confidence. Values are positive loss magnitudes, not maximum
   losses or future guarantees.
3. Rolling next-period VaR exception checks. Each forecast uses strictly older
   observations; displays number of tests, observed vs expected breaches and
   Kupiec unconditional-coverage p-values with sparse-event caution.
4. Observed historical worst common-date and 20-period compounded losses,
   plus optional instantaneous user-defined asset shocks (e.g. BTC-USD=-30).
5. Reuse of V1–V4 data adapters, FX conventions, validated shared dates,
   backtest NAV, fee parameters and existing CLI, with structured JSON output.
6. Fixed V4 CLI strategy table formatting (headings display correctly).

LIMITATIONS
-----------
The available sample omits earlier crises and pre-inception fund periods.
Quarterly/monthly market calendars use shared observed closes; Bitcoin has
additional weekend data. Price histories are FX-converted adjusted-return
proxies; idealized close executions and fractional assets are not real trades.
Asset risk attribution uses trailing covariance and ending weights, not the
full fee-inclusive historical risk contribution path. Normal VaR/ES assumes
normal returns; Kupiec coverage evaluates unconditional breach frequency, not
breach independence. At 99% confidence, expected breaches are sparse and
statistical inference is weak. No method guarantees the size of future losses.

HANDOFF
-------
V6: risk-sensitive portfolio construction and simple systematic rules.
We will use only past information to set dynamic weights, apply the existing
fee-aware V4 simulation framework, compare against reference allocations on
an identical evaluation period, and explicitly disclose hindsight selection.
